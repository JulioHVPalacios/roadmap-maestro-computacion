# Contribuir al Roadmap Maestro

Gracias por ayudar a mantener una ruta abierta, rigurosa y gratuita.

## Antes de proponer contenido

Comprueba que el tema no esté ya cubierto en `src/roadmap-data.ts` (S0–S19) o `src/mastery-data.ts` (T01–T12). Una nueva tecnología o puesto laboral no justifica por sí solo una ruta nueva.

## Una propuesta aceptable debe incluir

- hueco curricular concreto;
- prerrequisitos;
- qué estudiar;
- fuente exacta y ubicación dentro de la fuente;
- idioma;
- confirmación de acceso gratuito al material obligatorio;
- práctica/evidencia;
- forma de evaluación;
- razón por la que no duplica otra unidad.

## Preferencia de fuentes

1. universidad/documentación oficial;
2. repositorio educativo mantenido con teoría + práctica;
3. laboratorio abierto y reproducible;
4. recurso comunitario como complemento.

No se añadirá un recurso únicamente por número de estrellas, marketing o popularidad.

## Seguridad

No se aceptan instrucciones para atacar sistemas de terceros, robar credenciales, desplegar malware, evadir controles o cometer fraude. La formación ofensiva debe ser reproducible en un laboratorio autorizado.

## Verificación técnica

Antes de enviar un PR:

```bash
npm install
npm run build
```

Además verifica manualmente los enlaces modificados y revisa la interfaz en escritorio y móvil.
