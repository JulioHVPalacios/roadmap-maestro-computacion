# DESIGN_SYSTEM.md — Identidad visual

## Lenguaje base

Variables V41 principales:
- tinta `#10110f`
- papel `#fffef9`
- superficie suave `#f4f3ed`
- lima `#d8ff4f`
- verde `#087a58`
- rosa `#ff58c7`
- azul/cian `#73d7ff`
- radio base `28px`

Tipografías:
- Geist Variable
- Plus Jakarta Sans Variable

## Principios

- papel claro predominante;
- color como acento;
- bordes sutiles y profundidad moderada;
- animación con intención;
- evitar estética genérica de dashboard/IA;
- evitar glassmorphism indiscriminado y tarjetas idénticas;
- no mostrar textos sobre IA, prompts, parches o versiones internas.

## Programación

- zona docente clara;
- entorno técnico oscuro cuando sea necesario;
- transición coherente teoría ↔ laboratorio;
- Code Studio profesional, no decorativo.

## Responsive

Comprobar móvil, tablet, laptop y escritorio ancho. Evitar overflow, texto cortado, controles touch pequeños y canvas/editor que rompa layout.
