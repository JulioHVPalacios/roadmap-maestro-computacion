# Seguridad

No publiques vulnerabilidades, credenciales, datos personales ni enlaces maliciosos en un *issue* público.

Si encuentras un problema de seguridad:

1. evita explotarlo o recopilar información de otras personas;
2. prepara una descripción mínima reproducible;
3. utiliza **Security → Report a vulnerability** en GitHub cuando el repositorio tenga habilitado el reporte privado.

Este proyecto no necesita servidor, base de datos ni credenciales. El progreso se guarda únicamente en el navegador de cada visitante mediante `localStorage`.
