# Campus Maestro V15 — Base de investigación y auditoría

## Objetivo
Construir una ruta autodidacta de computación integral, gratuita y español-primero, que combine teoría, práctica, proyectos, evaluación, investigación y actualización continua. No se presenta como garantía automática de ser “número uno del mundo”; se diseña como un sistema de máxima cobertura y exigencia verificable.

## Regla S/0
Ninguna certificación, examen pagado, cloud de pago o suscripción puede ser requisito obligatorio. Cuando una fuente tenga una parte de pago, el Campus debe enlazar únicamente el material gratuito o proporcionar una alternativa gratuita y legal que cubra la misma competencia.

## Regla de evidencia
Cada materia debe contener: qué estudiar, fuente(s), práctica, evidencia evaluable, gate y proyecto/capstone cuando corresponda.

## Seguridad
La ofensiva se limita a sistemas propios, laboratorios, CTF y autorización explícita. El estudio de ciberdelito/black-hat se aborda como amenazas, análisis, prevención, DFIR, malware, derecho y defensa; no como instrucciones para atacar terceros.

## Producto
Campus Maestro evoluciona como universidad abierta + plataforma profesional pública de Julio Humberto Vera Palacios: portafolio, proyectos, sistemas/ERP, software, aplicaciones, videojuegos, investigación, noticias, publicaciones, comunidad/foro y servicios profesionales.
