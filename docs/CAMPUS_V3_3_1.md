# Campus Maestro v3.3.1

Hotfix y mejora cinematográfica: el mapa de conocimiento deja de depender del desplazamiento como línea de tiempo. La escena se reproduce automáticamente mientras está visible, se pausa al salir de pantalla, permite pausa/reproducción y salto por capítulos, y mantiene `prefers-reduced-motion`. También se contiene la escena para impedir solapamientos visuales sobre Auditoría u otras secciones.
