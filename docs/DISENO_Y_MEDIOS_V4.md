# Campus Maestro v4.0 — sistema visual profesional

La interfaz v4 abandona la lógica de "parches visuales aislados" y aplica un sistema único al campus completo: movimiento automático controlable, fondos con profundidad, fotografías reales verificadas, iconografía SVG consistente, tarjetas con interacción, transiciones de sección, navegación clara y modo claro/oscuro.

## Principios

1. Movimiento con propósito: autoplay + control manual; no depender del scroll para reproducir una narrativa.
2. Apariencia editorial/profesional: jerarquía tipográfica, retícula, espacios consistentes, iconos SVG y fotografías documentales reales.
3. Nada de fotos generadas presentadas como reales.
4. Accesibilidad: `prefers-reduced-motion`, contraste y navegación con botones reales.
5. Rendimiento: Auditoría sigue con carga diferida y las imágenes usan carga perezosa salvo la primera.
