## Nota de build

El entorno de creación de esta entrega no pudo instalar las dependencias npm desde Internet, por lo que no se declara falsamente un `npm run build` local completado. El repositorio conserva el workflow de GitHub Pages, que instalará dependencias y ejecutará el build en GitHub Actions al publicarse.

## Política de enlaces

La existencia de un enlace no garantiza que un tercero no lo cambie en el futuro. Por eso el repositorio incluye un workflow de revisión periódica y una política de sustitución documentada.
