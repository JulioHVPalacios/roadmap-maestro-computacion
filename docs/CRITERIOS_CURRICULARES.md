# Criterios curriculares v2

## 1. Arquitectura: tronco + maestría

La v2 usa dos niveles:

- **S0–S19 (tronco):** fundamentos comunes que deben dominarse en orden.
- **T01–T12 (rutas de maestría):** profundidad especializada. Para la meta de cobertura total se completan las doce; para una carrera concreta se seleccionan según el mapa profesional.

Esto evita dos errores: comprimir disciplinas enteras en una sola materia y, en el extremo contrario, repetir el mismo fundamento bajo decenas de nombres de puestos.

## 2. Unidad básica: dominio demostrable

Cada etapa/unidad combina:

1. prerrequisitos;
2. teoría;
3. problemas/laboratorio;
4. evidencia reproducible;
5. proyecto cuando corresponde;
6. puerta de aprobación.

Marcar una unidad significa poder reconstruir y explicar el trabajo sin tutorial paso a paso.

## 3. Distribución recomendada

- 35 % teoría y apuntes propios;
- 45 % problemas y laboratorios;
- 15 % proyecto integrador;
- 5 % bitácora, revisión y explicación oral.

En investigación la proporción cambia hacia lectura de papers, reproducción y experimentación.

## 4. Jerarquía de fuentes

1. **Validadores curriculares:** FING, CS2023 y guías universitarias.
2. **Tronco docente:** OpenFING y FAMAF.
3. **Profundidad/evaluación:** UBA, UTN, UNLP, UOC.
4. **Laboratorios/especialidades:** Full Stack Open, FIUBA CEIA, Cisco, Microsoft Learn, ingeniería de datos, Godot, Blender, UNAM.
5. **Auditores/catálogos:** OSSU, roadmap.sh y roadmaps especializados.

Un recurso popular no entra si no resuelve un hueco real.

## 5. Costo obligatorio cero

- El material necesario para aprobar una unidad debe poder estudiarse sin pagar.
- Certificados, exámenes de certificación, cuentas cloud pagas, hardware y software comercial son opcionales.
- Si un laboratorio exige gasto, debe existir una alternativa local, simulada, open source o gratuita.

## 6. Idioma

- Español primero.
- Portugués puede funcionar como segundo respaldo cercano cuando sea útil.
- Inglés se usa en frontera o documentación sin equivalente suficiente, marcado como `EN→ES` y estudiado mediante traducción.
- La ruta recomienda desarrollar lectura técnica en inglés como competencia profesional, pero no la usa para bloquear el comienzo.

## 7. Seguridad

Toda práctica ofensiva queda limitada a sistemas propios, CTF, laboratorios o autorización explícita. Actividades delictivas citadas en taxonomías históricas/profesionales no se convierten en objetivos formativos.

## 8. Actualización

Semestralmente se revisan enlaces, gratuidad, ramas activas y huecos. La actualización de herramientas nunca debe borrar fundamentos matemáticos, algorítmicos, de sistemas o de ingeniería.
